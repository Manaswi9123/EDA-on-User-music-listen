# EDA-on-User-music-listen
# 🎵 Music Listening Behavior - Exploratory Data Analysis (EDA)

This project performs a comprehensive Exploratory Data Analysis (EDA) on a music streaming dataset. The goal is to uncover patterns in user behavior, platform preferences, and the relationship between music genres and user demographics.

---

## 🛠️ The Data Science Stack
* **Pandas:** For data cleaning, filtering, and structured manipulation.
* **NumPy:** For numerical operations and array handling.
* **Matplotlib:** For core plotting and visualization.
* **Seaborn:** For advanced statistical data visualization.
* **Scikit-Learn:** Used for data preprocessing (Label Encoding and Scaling).

---

## 📊 Project Workflow

### 1. Data Cleaning & Inspection
* Initial check for missing values and data types.
* Handling categorical variables to prepare for analysis.
* Statistical summaries to understand the distribution of listening hours and ages.

### 2. Exploratory Data Analysis (EDA)
I focused on answering key behavioral questions through visualization:
* **Platform Popularity:** Identifying which streaming services are most used.
* **Genre Analysis:** Visualizing the most popular music genres among users.
* **Demographic Trends:** Analyzing how age groups interact with different types of music.
* **Correlation Analysis:** Using Heatmaps to find relationships between different numerical features.

### 3. Data Preprocessing
To prepare the data for potential future Machine Learning models:
* **Label Encoding:** Converting categorical text data into numerical format.
* **Feature Scaling:** Standardizing numerical values for better model performance.

---

## 🚀 Key Visualizations Included
* **Count Plots:** For categorical distribution (Platforms, Genres).
* **Box Plots:** To identify outliers in listening time.
* **Heatmaps:** To visualize the correlation matrix of the dataset features.
* **Histograms:** To view the distribution of user ages.
